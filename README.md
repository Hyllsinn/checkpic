# CheckPic

Vérification humaine des photos de poissons corrigées par les pêcheurs de River’Sense, avant
tout réentraînement du modèle. Accès réservé (compte administrateur).

```bash
npm install
npm run dev
```

Contrôles : `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.
Règles et sécurité : voir `AGENTS.md`.
